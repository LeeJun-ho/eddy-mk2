## STEP 1 — 코드베이스 탐색

요구사항과 관련된 아래 항목을 파악해줘.

- 관련 엔티티, DTO, enum
- 관련 서비스, 컨트롤러, 모듈
- 재사용 가능한 기존 함수, 유틸리티, 패턴
- 변경이 필요한 파일과 그 이유

## STEP 2 — 요구사항 정리

코드베이스 탐색 결과를 바탕으로 아래 항목을 정리해줘.

1. **목적** — 이 기능이 왜 필요한지, 어떤 문제를 해결하는지
2. **기능 요구사항** — 사용자 관점에서 무엇을 할 수 있어야 하는지
3. **비즈니스 규칙** — 기존 코드베이스를 고려한 도메인 정책과 조건
4. **예외 케이스** — 허용되지 않는 입력, 경계값, 기존 제약 조건 기반 오류 상황
5. **비기능 요구사항** — 성능, 보안, 제약 조건 등 (해당되는 경우)

## STEP 3 — 구현 계획

1. **변경 파일 목록** — 생성/수정할 파일 경로와 변경 이유
2. **구현 세부 내용** — 파일별로 추가/수정할 함수·클래스·타입을 구체적으로 정리
3. **구현 순서** — 의존 관계를 고려한 작업 순서
4. **주의사항** — 사이드 이펙트, 기존 기능에 영향을 줄 수 있는 부분
