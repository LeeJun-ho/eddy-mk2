`local/context/{{taskId}}/spec.md`의 요구사항을 바탕으로 구현 계획을 수립해줘.

## 사전 조사

계획을 작성하기 전에 아래 항목을 먼저 파악해줘.

- 요구사항과 관련된 기존 코드 구조 (엔티티, 서비스, 컨트롤러, 모듈 등)
- 재사용할 수 있는 기존 함수, 유틸리티, 패턴
- 변경이 필요한 파일과 그 이유

## 계획 작성 항목

1. **변경 파일 목록** — 생성/수정할 파일 경로와 변경 이유
2. **구현 세부 내용** — 파일별로 추가/수정할 함수·클래스·타입을 구체적으로 정리
3. **구현 순서** — 의존 관계를 고려한 작업 순서
4. **주의사항** — 사이드 이펙트, 기존 기능에 영향을 줄 수 있는 부분

## 출력

`local/context/{{taskId}}/plan.md` 파일이 이미 존재하면 이 단계를 건너뛰고 다음 단계로 진행해줘.
존재하지 않으면 작성한 계획을 해당 경로에 저장하고, 반드시 파일 마지막 줄에 영문으로 `DONE`을 추가해줘.
