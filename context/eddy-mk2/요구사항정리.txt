# eddy-mk2 요구사항 정리

## 프로젝트 개요

업무 자동화 배치 서버.
작업 목록(SQLite)을 기반으로 Claude Code가 자동으로 코드를 작성하며, 
작업에 Jira 티켓 번호가 있을 경우 해당 티켓의 요구사항을 반영한다.
여러 프로젝트를 대상으로 동작한다.

---

## 핵심 기능

### 1. 작업 목록 관리 (SQLite)
- 수행할 작업 목록을 SQLite에 저장한다.
- 각 작업은 상태값을 가진다 (예: 대기 / 진행중 / 완료 / 실패).
- 작업 수행 결과에 따라 상태를 업데이트한다.
- 작업에 Jira 티켓 번호가 있을 경우, Jira 티켓의 요구사항을 가져와 개발 내용으로 활용한다.

### 2. Claude Code 코딩 자동화
- 작업 목록에서 순차적으로 작업을 꺼내 Claude Code에 전달한다.
- Claude Code가 작업 목록에 정의된 요구사항에 맞는 코드를 작성한다.
- 코드 작성 완료 후 Jira 티켓 상태도 함께 변경한다.
- PR 생성은 수행하지 않는다.

### 3. 순차 실행 흐름
- 스케줄에 따라 작업 목록을 주기적으로 폴링한다.
- 작업 하나가 완료되면 서버에 알림을 보낸다.
- 서버는 알림을 받아 다음 작업을 실행한다 (체인 방식).

---

## 대상 프로젝트

- 단일 프로젝트가 아닌 여러 레포지토리를 대상으로 동작.
- 각 티켓에 대상 레포지토리 정보가 포함될 것으로 예상.
